02Problem catalog (P1–P12, brutal honesty)

P4 · Medium

Spelling drift between semantic axes: "error" vs "danger"

feedback/styles.go (FeedbackError) ↔ utils/tone/tone.go (ToneDanger)

The canonical feedback enum spells the failure level "error" while the tone axis spells it "danger"; the adapter maps one onto the other. Two names for one concept across the boundary is exactly the split-brain the rubric hunts. Known and scheduled: the map collapses into the tone tables at v2 (TODO #431), after which one spelling survives.

P3 · Deliberate

Invalid enum values render a fallback instead of failing

utils.Lookup(m, key, fallback) call sites

A struct can be constructed with Type: FeedbackType("nope") and it compiles — then renders the neutral fallback. This is a documented tradeoff, not an oversight: it is a render library, a panic inside a consumer's render path is a shipped bug, and the only permitted panic is the icons path-integrity check. Invalid-state detection exists where it matters (IsValid guards, 90 of them) for programmatic checks, goldens pin the rendered output, and the graceful-degradation rule (e.g. AvatarStatus unknown renders no dot) is tested.

P10 · Deliberate

templ.Attributes is an open map[string]any

utils.BaseProps.Attrs

The one stringly-typed escape hatch. HTML attributes are an open set; typing them would mean wrapping the entire HTML spec. It stays, documented as the sanctioned boundary, with CSP and ARIA compliance enforced by dedicated scan guards rather than the type system.

P4 · Low

BaseProps scalar fields are raw strings

utils.BaseProps (ID, Class, AriaLabel, Nonce)

Nonce could be a branded type; ID and AriaLabel are irreducibly strings in their domain (CSS-selector-safe IDs are validated at use sites via SanitizeID/EnsureID). A type Nonce string would prevent passing an ID where a nonce belongs — a mistake with no observed instances. Rejected for now: branding cost (every props literal and helper signature changes, breaking) vs a hypothetical bug class. Revisit at v2 alongside the tone collapse.

03The vision

  • Every closed set is a typed enum with an IsValid guard and a test — already true, stays true.
  • One color language: tone.Tone (why) + tone.Hue (which pigment), all lookups through the two tables — the v2 collapse finishes this.
  • Every props struct embeds BaseProps and satisfies ComponentProps, so generic wrappers work uniformly — true today.
  • One transport struct (wire.Action) whose zero value means the documented default — true today, guarded by tests.
  • Render paths never panic; unknown values degrade to tested fallbacks — true today.
  • Errors cross module boundaries through one classified interface (go-error-family) extracted via errors.AsType — true today.

04The model, as built

// The shared kernel: every props struct embeds this (utils/utils.go).
type BaseProps struct {
    ID        string
    Class     string
    Attrs     templ.Attributes   // the sanctioned open boundary
    AriaLabel string
    Nonce     string            // "" omits the attribute, never nonce=""
}

// The uniform composition contract (pointer receivers, auto-satisfied).
type ComponentProps interface {
    GetBaseProps() BaseProps
    SetBaseProps(props BaseProps)
}

// Every closed set is a typed string enum (60 of them), with a guard:
type FeedbackType string // success | error | warning | info
func ToneIsValid(t Tone) bool  // 90 IsValid-family guards repo-wide

// Style lookups: typed key, explicit fallback, never a panic.
func Lookup[K comparable, V any](m map[K]V, key K, fallback V) V

// One transport struct; zero values ARE the documented defaults.
type Action struct {
    Transport   Transport    // "" renders htmx (ADR-0030)
    Method      Method       // "" renders GET in both dialects
    URL         string       // "" wires nothing (inert, not broken)
    Event, Target, ContentType // ...typed sub-enums, not strings
}

// The color language (v2 target): semantic axis + pigment axis.
type Tone string // neutral | success | warning | danger | info | accent
type Hue string  // categorical pigments for series/lanes

06Validation layer

The library makes invalid states harmless rather than unrepresentable — a conscious inversion of the usual slogan, forced by the render-path-no-panic constraint. The layers:

  • Construction: typed enums + DefaultXxxProps() constructors; struct-literal zero values equal the documented defaults (inverted flags like NoPad/NoValidate), consumer-audited and guarded.
  • Programmatic checks: 90 IsValid guards for code that wants to reject early.
  • Render fallback: every lookup has an explicit fallback; unknown enum ⇒ neutral/default classes, tested per component.
  • Output pinning: 332 goldens + visual suite + axe gate catch anything the type system cannot express (class regressions, ARIA drift, dark-mode misses).
  • Error boundary: consumers' handler errors classify through go-error-family; extraction via errors.AsType[errorfamily.Classified]; unknown errors degrade to FamilyCorruption (500), never a panic.

08Anti-patterns (traps for contributors)

Do not add map[string]string style lookups

New variants get typed enum keys through utils.Lookup — string keys reopen P1 and lose the IsValid guard.

Do not concatenate Tailwind variants at runtime

The scanner only emits CSS for complete literal tokens; dynamic prefixes produce classes with no stylesheet. Tone Pair exists so light/dark halves stay structural.

Do not migrate errors.Is to AsType reflexively

Sentinel matching (io.EOF, context.Canceled, package sentinels) belongs to errors.Is. This repo has zero current findings; keep it that way case-by-case, not by linter-driven mass migration.

Do not add pointer fields to props structs for "not yet"

Use inverted flags for defaults-on and typed enums for modes; pointers are reserved for genuinely optional associations (*wire.Action) and test tri-states.

09Migration roadmap

1

Now — nothing blocking

The model needs no remediation to keep shipping v1.x. All findings are scheduled v2 events or documented tradeoffs.

2

v2 event 1 — tone collapse (TODO #425/#431)

Existing enums (FeedbackType, AlertType lineage, status enums) become thin aliases/adapters; the tone tables become the only style source; the "error"/"danger" spelling converges. Equivalence tests from Phase 0 make this mechanical.

3

v2 event 2 — optional BaseProps branding

Only if v2 already breaks BaseProps consumers: brand Nonce (and consider ID) in the same release to keep the breaking-change budget to one event.

4

Ongoing — hold the guard lines

IsValid-with-test per new enum, goldens per component, erraudit clean, zero runtime panics (TestZeroRuntimePanics), scanner-literal rule. These guards ARE the model's type system for everything Go's types cannot express.

Conclusion This is what a mature library data model looks like: not zero stringly-typed code, but zero accidental stringly-typed code — every remaining string is either a domain string (HTML, CSS, IDs) or a scheduled v2 event with a test-proven bridge.
