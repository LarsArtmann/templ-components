04Hygiene findings (Phases 1.3, 2.6)

H1 — go-error-family pin skew (found + fixed)

errorpage/go.mod (the direct consumer) required go-error-family v0.11.0 while root, visualtest, and website carried v0.12.0. Provenance: the daemon's go mod tidy bumped the indirect consumers (2026-10-18) but nothing touched the direct require; Dependabot's proper fix branch also carried the unwanted templ v0.3.1100 bump and was abandoned. Workspace MVS masked the skew in dev; only a GOWORK=off build of errorpage used v0.11.0.

Fix, per docs/external-dependency-bumps.md: source-verified both versions (zero exported-API delta; v0.12.0 adds only a nil-receiver-safe Unwrap), bumped errorpage to v0.12.0, go mod tidy, build + tests green, replace-directive guard still OK, no v0.11.0 pins remain.
