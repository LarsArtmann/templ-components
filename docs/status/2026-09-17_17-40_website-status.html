05What We Should Improve

+
Enforce the website suite in CI (one YAML line) The integrity test renders the whole site and checks links, nonces, sitemap, search index. CI never runs it. This is the single cheapest reliability upgrade available.
+
Derive, don't restate, any committed number that mirrors code Third time this pattern pays (drift guard, CSS freshness, CSP hashes). The comparison-matrix fix generalizes it: if a literal restates a code fact, replace it with the computation.
+
Daemon needs a build gate before committing Three CI reds in one day, two from foreign-session snapshots. Even a bare go build ./... per module before commit would have blocked all three.
+
Read claims about "impossible by construction" as falsifiable hypotheses The drift-guard comment claimed website drift couldn't happen; prose numbers disproved it within four days. Guards age better than claims.
