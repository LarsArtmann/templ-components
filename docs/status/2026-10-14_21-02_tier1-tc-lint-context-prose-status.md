## e) IMPROVEMENTS

- **The choke-point pilot beat the planned pilot.** The plan said "pick the smallest script emitter (candidate: utils.Dismiss)"; research showed Dismiss renders through `utils.ScriptComponent`, so context-readiness landed in ONE function and covers every script-emitting component with zero signature churn. Future plan sketches should be treated as hypotheses to beat, not contracts.
- **`os.Root`-scoped walking is the new scanner standard.** `scanSources` (Root.FS + ReadFile(rel)) satisfies gosec G122 without nolint, can't be symlink-walked out of the target, and returns honest errors for missing dirs — reuse it for any future file-walking guard.
- **Guard-refactor shape that keeps history honest:** keep the guard test's dir list + output format in the `_test.go`, move only the engine to the non-test file, and filter multi-rule scanners by rule id so each guard's semantics stay byte-identical. All four refactors (RTL/dark/motion/icons) followed it cleanly.
- **Exception tables must be consumer-safe by construction:** dark-mode exceptions match on reconstructed library-relative paths (inert on consumer trees); consumers get the per-line allowlist instead. This split should be the template for any future scanner with built-in exemptions.
- **The verification ladder worked, and caught real things:** the counts guard caught the website goldens; ci-repro caught that same drift one layer deeper; the visual suite caught the intended display drift. Every gate that fired was a gate earning its keep — no false positives all session.
- **Working WITH the daemon:** verify-edit-survived after every long command (`git show --stat`), amend generic messages pre-push only, commit urgent fixes yourself the moment they're ready (the website-golden fix), and expect ~60s races on anything long-running.
