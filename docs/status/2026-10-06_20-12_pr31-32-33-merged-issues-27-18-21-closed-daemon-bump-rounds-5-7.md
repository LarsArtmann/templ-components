## e) WHAT WE SHOULD IMPROVE

1. **After ANY failed pre-commit: audit the index before the retry.** `git diff --cached --stat` must show ONLY what you intended. Guard 8 (mirror sync) and formatter providers stage fixes that legitimately survive a failed run — and silently ride the retry commit (this is documented for the success path; the failure path is the trap).
2. **Never pipe `git commit` through `tail` inside an `&&` chain.** Sequence with `;` + explicit `echo exit=$?`, or capture to a file. The exit status of a pipeline is its LAST command — d1 is the third instance of this class in the repo's history.
3. **Temp-worktree surgery: `--no-verify` from the first conclusion commit** for merges of CI-green content (now codified in AGENTS via `20a18f5b`); the pushed branch's CI is the gate. Probe lint directly only if you actually doubt the content.
4. **Conflict resolutions: read BOTH sides fully before composing the replacement** — the d2 slip came from assembling the union from memory instead of re-reading the block. The `edit`-tool discipline (exact match) applies to conflict authoring too.
