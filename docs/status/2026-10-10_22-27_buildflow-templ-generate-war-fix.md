**The one-paragraph story:** BuildFlow's `templ-generate` step regenerated the `cmd/tc/_sources` scaffolder mirror's `.templ` copies **in place** (its file walk pruned `.`-prefixed dirs but not `_`-prefixed ones, so the root go.mod "owned" `cmd/tc/_sources/**/*.templ`), producing 112 `*_templ.go` strays with mirror-path `FileName` metadata inside the embed mirror. The auto-commit daemon committed them (third add/remove war cycle that day: `c4fde801` added → `51d1694e` removed → `990ddde0` re-added), and because `//go:embed all:_sources` embeds **even gitignored** files, every `cmd/tc` test failed. Fixed at three layers: local (gitignore + guard + Go test), upstream (BuildFlow `ShouldSkipDir` `_`-prefix prune, matching the Go toolchain AND templ's own `internal/skipdir`), and process (verified with the FULL pipeline, not a cached single step).
