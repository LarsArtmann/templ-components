Detected immediately via `jj st`, file removed, no push happened while wrong. Lesson: never gate `&&` behind a piped command.
2. **Scratch package created inside the repo root** (`pr1447verify/`) with no `.git/info/exclude` guard while the auto-commit daemon was actively committing (it committed 3+ times during this session). It survived ~2 minutes and was trashed before any daemon cycle hit it. The later banner tool DID use the exclude guard — the safe pattern was adopted one scratch too late.
