## What v1.24.0 ships (highlights)

- **New components / surfaces:** `display.Prose` (longform `.tc-prose` family),
  `tc lint` (four compliance scanners as a consumer CLI), `errorpage.FamilyFromStatus`,
  `errorpage.WriteNotFound404Document`, `NotFound404Props.GoBackText` +
  `SearchSubmitLabel`, CSP-safe `data-tc-overlay-trigger`, `cmd/site --skip-stars`.
- **Colour/type system:** `utils/tone` Phase 0 (canonical Tone/Hue), typed
  `tone.ColorClass` on nine colour props, one `display.Position` enum for every
  floating component, typed `feedback.StepState`, generated theme-bridge table.
- **Correctness fixes:** SegmentBar/CopyButton/Table ARIA nesting, Heatmap leaf
  role, PolledRegion contrast, `MetaRefresh` valid markup, context-injected
  nonce defaults (ADR-0047), Print layer, `layout.Split` aside semantics.
- **Tooling (internal, listed for completeness):** honesty-split coverage script
  - baseline guard, staged-Go settle guard, deterministic site builds, CI runner
    hygiene.
